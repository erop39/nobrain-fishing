# Диагностика

## Программа не запускается: `No module named PIL`

Pillow импортируется как `PIL`. Установите компоненты через `install-components.bat` или:

```powershell
.venv\Scripts\python.exe -m pip install Pillow
```

В актуальном коде отсутствие Pillow не должно останавливать звуковой режим, но визуальные функции и иконка трея будут недоступны.

## Мониторинг сразу останавливается: `Error 0x800401F0`

Это `CO_E_NOTINITIALIZED`: COM не инициализирован для аудиопотока Windows. В v1.4+ предусмотрена инициализация COM внутри рабочего потока WASAPI. Если ошибка повторяется, приложите свежий лог, номер версии и используемое аудиоустройство.

## `AUDIO rms_max=0`, `SILENT`

Детектор получает цифровую тишину. Проверьте, что звук RustDesk реально идёт на **тот же** выход, который выбран в приложении, и что в Windows аудиопоток не заглушён. Проверьте `CABLE Input`, обновите устройства и повторите тест с выключенной автоматизацией.

## Поклёвка слышна, но `DETECT` отсутствует

Сопоставьте `AUDIO peak`/`CANDIDATE best_score` с порогом. Слишком высокий порог отсекает поклёвки, слишком низкий вызывает ложные срабатывания. Начните с **0.65**, используйте проверенный `bite_sample.wav`. Запишите несколько реальных поклёвок с логами, не меняя другие параметры одновременно.

## Отправка `Space` отмечена, но в WoW ничего не происходит

Проверьте активное окно (`FOCUS`), тестовую кнопку `SPACE через 3 секунды`, настройку аддона **Forever Fishing** и разные методы `ScanCode / VirtualKey / Legacy`. Запись `INPUT` подтверждает попытку отправки в Windows, но не факт обработки клавиши игрой.

## Окно стало большим / отсутствует прокрутка

Начиная с v1.4 длинные вкладки прокручиваются. Положение и размеры хранятся в `settings.json`. Если окно осталось за пределами экрана после смены разрешения, закройте приложение и временно переименуйте `settings.json`, чтобы сбросить параметры интерфейса.

## Визуальный режим не находит поплавок

Проверьте Pillow и OpenCV, маленькую обрезанную фотографию реального поплавка, основной монитор и видимость окна WoW/удалённого сеанса. Автопоиск — экспериментальный; фоновые изображения, рябь и освещение способны приводить к ошибкам. Используйте режим «Звук» как базовый.

## Установка компонентов не завершается

Проверьте доступность PyPI, Python Launcher и `.venv`, затем вручную:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-optional.txt
```

## Что приложить к сообщению об ошибке

Версию приложения, режим (локальный/удалённый), выбранный аудиовыход, распознавание (звук/пиксели), последние строки из `logs/` и описание ожидаемого/фактического поведения. Не публикуйте журналы, если в них есть личные названия окон или компьютеров.
