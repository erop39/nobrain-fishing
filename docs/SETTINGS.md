# Справочник настроек Nobrain Companion v1.5

Настройки сохраняются в `settings.json` после нажатия «Сохранить настройки». Интерфейс состоит из семи вкладок; дополнительные действия расположены в верхней панели.

## 🎣 Рыбалка

| Параметр | Значение / назначение |
|---|---|
| **Автоматически нажимать SPACE** | Включает отправку клавиши при забросе и подсечке. Без галочки идёт только наблюдение. Нужен аддон **Forever Fishing** с назначением обеих функций на Space. |
| **Ожидание поклёвки** | `30 с` по умолчанию: после заброса отсутствие детекции приводит к тайм-ауту и следующему забросу. Минимум при сохранении — `3 с`. |
| **Задержка подсечки MIN/MAX** | По умолчанию `0.10–0.25 с`, диапазон двойного ползунка `0–2 с`, шаг `0.05 с`. Задержка отсчитывается после срабатывания детектора. |
| **Пауза перезаброса MIN/MAX** | По умолчанию `1.0–2.0 с`, диапазон `0–8 с`, шаг `0.1 с`. Используется после подсечки и тайм-аута. |
| **Старт / Пауза / Стоп** | Запускает мониторинг; приостановка сохраняет состояние; стоп завершает цикл. |

Паузы выбираются случайно **внутри заданных диапазонов**. Они не компенсируют задержки сети RustDesk или буферизации звука.

## 🔊 Звук

| Параметр | Назначение |
|---|---|
| **Источник звука Windows** | Устройство воспроизведения, которое программа читает через WASAPI Loopback. `System default` — системное устройство; для тихого режима — `CABLE Input (VB-Audio Virtual Cable)`. |
| **Обновить устройства** | Повторно перечисляет аудиовыходы. |
| **Настройка бесшумного звука** | Открывает пояснение по перенаправлению звука через виртуальный аудиокабель. |
| **Слушать (до 90 с)** | Запускает накопление аудио, чтобы поймать нужный звук без попадания в короткий интервал записи. |
| **Сохранить недавний всплеск** | Выбирает недавний звуковой фрагмент и сохраняет WAV-образец. |
| **Добавить WAV** | Импортирует образец в локальную библиотеку. |
| **Активный звуковой файл** | Выбирает сохранённый WAV. Имя активного файла отображается в интерфейсе. |
| **Порог совпадения (0–1)** | По умолчанию `0.65`. Меньше — чувствительнее, но больше риск ложных срабатываний. |
| **Периодические AUDIO/CANDIDATE события** | Печатает в журнал диагностику найденных совпадений, даже если порог не пройден. |
| **Интервал журнала** | По умолчанию `3 с`, допустимо `1–30 с`. |

`bite_sample.wav` в корне — готовый короткий эталон (около 0.95 с). `samples/bite.wav` — дополнительная запись (~2.55 с); активный участок автоматически выделяется по энергии. Не меняйте порог, пока в логе `rms_max=0`: это отсутствие аудиосигнала, а не слабое совпадение.

## 👁 Пиксели

| Параметр | Назначение |
|---|---|
| **Режим распознавания** | `Звук` (основной); `Пиксели (эксперимент)`; `Звук ИЛИ пиксели` (достаточно одного детектора). |
| **Выделить область поплавка** | Ручной прямоугольник на экране; актуален для статичного положения объекта. |
| **Порог изменения пикселей** | По умолчанию `0.22` в пределах `0.05–0.95`; больше — требуется более существенное изменение изображения. |
| **Искать поплавок по фотографии после заброса** | Экспериментальный поиск образца на основном экране с несколькими масштабами и отслеживанием области после обнаружения. Требует OpenCV и Pillow. |
| **Выбрать фото поплавка** | Небольшой PNG/JPG поплавка (рекомендуется обрезанный, без большой площади воды). |

Фиксированная область не перемещается автоматически. Фото-поиск пытается решить эту проблему, но может ошибаться на отражениях и при смене ракурса. Он **не захватывает скрытое окно**: нужен видимый кадр игры на основном экране.

## ⌨ Подключение

| Параметр | Назначение |
|---|---|
| **Удалённо / Локально** | Выбор между клиентом удалённого доступа и запущенным на этом ПК WoW. |
| **Окно WoW / PID** | В локальном режиме: `Автоопределение WoW` либо конкретный процесс из списка. Кнопка «Обновить» обновляет список. |
| **Клиент удалённого доступа** | `Auto`, `RustDesk`, `AnyDesk`, `TeamViewer`. Auto распознаёт заголовок окна. |
| **Автоматически активировать окно при старте** | Пытается вывести подходящее окно на передний план при нажатии «Старт». Если фокус недоступен — ввод приостанавливается. |
| **Метод отправки клавиши** | `ScanCode` (основной), `VirtualKey` и `Legacy` (альтернативы для диагностики). |
| **Тест SPACE через 3 секунды** | Проверка передачи клавиши без полного игрового цикла; успейте открыть целевое окно. |
| **При нажатии X** | `Сворачивать в трей` либо `Закрывать приложение`. Трей зависит от Pillow и pystray. |
| **Расположение окна** | Сохраняется и восстанавливается, ограничивается доступной высотой экрана. |

Обычная эмуляция ввода использует активное окно. При переключении в другое приложение нажатия WoW не гарантируются; проверка фокуса предназначена для предотвращения ошибочного ввода. Локальный режим также несёт риск санкций от игрового сервера.

## 📊 Статистика

| Счётчик | Значение |
|---|---|
| **Забросы** | Число отправленных команд заброса в текущей сессии. |
| **Поклёвки** | Число подтверждённых детектором событий. |
| **Предположительно поймано** | Примерная оценка по отправленным подсечкам; не чтение инвентаря WoW. |
| **−1 / +1 улов** | Ручная коррекция после срыва или пустой поклёвки. |
| **Сброс статистики** | Обнуляет счётчики сессии. |

## ⚙ Компоненты

Проверяет `numpy`, `scipy`, `soundcard`, `psutil`, `Pillow`, `pystray`, `opencv-python`. Кнопка **«Установить недостающие»** запускает `pip` через текущий `sys.executable`; нужен интернет. После установки дополнительных компонентов перезапустите программу. `install-components.bat` устанавливает полный комплект из файлов зависимостей.

## 📋 Журнал

Вкладка показывает последние события; кнопка **«Окно логов»** открывает отдельный просмотрщик. Полные журналы сохраняются в `logs/remote-fishing-ГГГГММДД-ЧЧММСС.log`.

Ключевые категории: `INFO` (запуск/остановка), `CAST` (заброс), `AUDIO` (уровень/совпадение), `CANDIDATE` (возможное совпадение), `DETECT` (порог пройден), `BITE` (подсечка отправлена), `TIMER` (30-секундный тайм-аут), `FOCUS` (активное окно), `INPUT` (отправка клавиши), `VISION`/`VISUAL` (визуальная детекция), `ERROR` (ошибки).

## Глобальные хоткеи

- `Ctrl+Alt+F6` — старт/продолжить.
- `Ctrl+Alt+F7` — пауза/продолжить.
- `Ctrl+Alt+F8` — стоп.
- `F8` — аварийный стоп.


### Звук + свой поплавок (строго)

Двухканальное подтверждение для уменьшения срабатываний на всплески других игроков. Поиск поплавка должен определить его положение после заброса. Звуковой кандидат сам по себе не запускает Space. Совпадение звука и изменения пикселей допускается в пределах 1,5 секунды. Режим экспериментальный.

### Минимальное время до подсечки
Опциональная галочка и ползунок 0–28 сек. По умолчанию выключено. Всплески, случившиеся раньше порога с момента заброса, записываются как `BITE_IGNORED` и не вызывают Space. Тайм-аут 30 сек. действует независимо.
