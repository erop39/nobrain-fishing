# Удалённый доступ и бесшумное аудио

## Проверенная схема RustDesk

```text
WoW (домашний ПК) -> звук в RustDesk -> рабочий ПК -> VB-CABLE Input
                                                    -> WASAPI Loopback -> Nobrain Companion
Nobrain Companion -> эмуляция Space -> активный RustDesk -> WoW
```

1. На домашнем компьютере включите звук WoW и передачу аудио RustDesk.
2. На рабочем компьютере установите [VB-CABLE](https://vb-audio.com/Cable/).
3. В Windows **Параметры → Система → Звук → Микшер громкости** назначьте для RustDesk выход **CABLE Input (VB-Audio Virtual Cable)**.
4. Не включайте `Listen to this device` / прослушивание **CABLE Output** через колонки — это нарушит бесшумный режим.
5. В Nobrain Companion выберите **CABLE Input** и нажмите «Старт» с выключенной автоматизацией. Убедитесь, что `AUDIO rms_max` становится больше нуля при игровых звуках.
6. При необходимости включите автоматизацию, выберите `RustDesk` и `ScanCode`. Для неё активное окно RustDesk должно быть на переднем плане.

Если Windows микшер заглушает саму дорожку приложения, loopback будет получать тишину. Вместо установки громкости RustDesk в 0 перенаправляйте звук в виртуальный кабель.

## AnyDesk и TeamViewer

Выберите соответствующий клиент на вкладке «Подключение». Проверьте **отдельно** два условия: аудио передаётся на выбранный Windows-выход, а `Test SPACE` доходит до удалённого окна. Поддержка определения окна встроена, но реальная передача синтетических клавиш зависит от версии клиента и настроек.

## Работа в фоне

Сам Nobrain Companion можно свернуть, сохранив аудиомониторинг. Однако **полностью скрытый клиент удалённого доступа** может перестать предоставлять кадр экрана для визуального режима. Автоматическая отправка Space в неактивное окно не подтверждена и не должна считаться поддерживаемой возможностью.
